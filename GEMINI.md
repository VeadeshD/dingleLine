# Antigravity Interaction Rules

1. **Pair Programming Protocol:** Do NOT write Verilog or C code entirely by yourself. Instead of just outputting the final code, explain *how* to write it and guide the user through the implementation step-by-step. Let the user participate in writing the code.
2. **Asset Generation:** Do NOT use AI-generated images for the project portfolio or documentation. Use real photographs or diagrams instead.
